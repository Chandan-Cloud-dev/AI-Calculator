# Modern Calculator

A clean, responsive calculator built with plain HTML, CSS, and JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Percentage, decimals, and positive/negative numbers
- Clear All (AC) and Delete (DEL)
- Full keyboard support
- Error handling, including division by zero
- Responsive design for mobile, tablet, and desktop

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 0–9 | Enter digits |
| . | Decimal point |
| + - * / | Operators |
| Enter or = | Calculate |
| Backspace | Delete last digit |
| Escape or Delete | Clear all |
| % | Percentage |

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
